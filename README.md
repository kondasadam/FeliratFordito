# Feliratfordító

Élő angol → magyar feliratfordító Androidra, kamerával. A szövegfelismerés és a fordítás a telefonon fut (Google ML Kit), internet csak az első indításkor kell.

**Letöltés a telefonon:** https://github.com/kondasadam/FeliratFordito/releases/latest/download/FeliratFordito.apk

Az APK-t a GitHub Actions építi automatikusan minden módosítás után.

## Felhasznált adatok

Az angol helyesírás-javítás szólistája a [FrequencyWords](https://github.com/hermitdave/FrequencyWords) projektből származik (OpenSubtitles 2018 alapján, CC BY-SA 4.0).
